## 화면 1 — 협찬요청 목록 (/requests)

```
┌─────────────────────────────────────────────┐
│  협찬요청 목록               [+ 새 요청 등록] │
│                                             │
│  상태 필터: [전체▼]                          │
│                                             │
│  ┌──────┬──────┬──────┬──────┬────────────┐ │
│  │ 행사명 │ 기업명 │ 수량 │ 상태  │  작성일시   │ │
│  ├──────┼──────┼──────┼──────┼────────────┤ │
│  │ 봄축제 │ 도미노 │  10  │ 승인  │ 2026-05-10 │ │
│  │ 체육대 │  CJ  │   5  │ 대기  │ 2026-05-12 │ │

│  └──────┴──────┴──────┴──────┴────────────┘ │
│           (행 클릭 → 상세 페이지)            │
└─────────────────────────────────────────────┘
```

**표시 컬럼:** 행사명, 기업명, 수량, 상태, 작성일시

## 화면 3 — 협찬요청 상세 (/requests/{id})

```
┌─────────────────────────────────────────────┐
│  협찬요청 상세                  [← 목록으로] │
│                                             │
│  행사    봄 축제 (2026-06-01, 한양대)        │
│  기업    도미노피자  /  상품: 피자           │
│  수량    10개                                │
│  상태    ● APPROVED                         │
│  작성일  2026-05-10                          │
│                                             │
│  ─────────── 상태 변경 ─────────────────    │
│  [OFFERED] [APPROVED] [SHIPPED] [DONE]      │
│  (현재 상태 이후 단계만 버튼 활성화)         │
│                                             │
│  ─────────── 후기 ──────────────────────    │
│  상태가 DONE일 때만 표시                     │
│  [후기 작성하기 →]                          │
└─────────────────────────────────────────────┘
```

**기능:** 상태 변경 버튼 (현재 다음 단계만 활성화), DONE일 때 후기 링크 표시

## Thymeleaf 파일 구조

```
resources/templates/
├── layout.html              ← 공통 레이아웃 (헤더, 네비)
├── request/
│   ├── list.html            ← 협찬요청 목록
│   ├── form.html            ← 협찬요청 등록
│   └── detail.html          ← 협찬요청 상세 + 상태 변경
├── review/
│   └── form.html            ← 후기 등록
└── stats/
    └── index.html           ← 통계 탭 전체
```
