## 화면 2 — 협찬요청 (/requests/new)

```
┌────────────────────────────────────────────────┐
│  협찬요청                                       │
│                                                │
│  학생단체  이화여대 컴퓨터공학과 학생회 (커밋)   │
│            (세션에서 자동 표시)                  │
│                                                │
│  행사      [선택하세요                  ▼]      │
│  기업      [선택하세요                  ▼]      │
│  수량      [      ]  ← 양의 정수만 허용          │
│                                                │
│                         [요청]                 │
└────────────────────────────────────────────────┘
```

**동작:**
- 행사/기업: DB에서 목록 조회해 dropdown 표시
- 수량: 빈값·0·음수 입력 시 에러 메시지 표시 (submit 전 검증)
- '요청' 클릭 → INSERT 직후 랜덤으로 APPROVED/REJECTED 결정
- APPROVED 시 10초 후 자동으로 DONE 전환 (백그라운드)
- alert("협찬 요청이 완료되었습니다.") → 협찬목록으로 이동
- 같은 행사+기업 중복 요청 시 에러 메시지 표시

## 화면 3 — 협찬목록 (/requests)

```
┌────────────────────────────────────────────────┐
│  협찬목록                                       │
│                                                │
│  ┌────────┬────────┬──────────┬────┬──────┬──┐ │
│  │학생단체명│  기업명  │   행사    │ 수량 │협찬상태│  │ │
│  ├────────┼────────┼──────────┼────┼──────┼──┤ │
│  │  커밋   │ 도미노  │  봄 대동제  │ 20 │ DONE │후기│ │
│  │  커밋   │  CJ   │ 취업 박람회  │ 10 │PENDING│  │ │
│  │  커밋   │  농심  │  해커톤    │ 30 │APPROVED│  │ │
│  └────────┴────────┴──────────┴────┴──────┴──┘ │
└────────────────────────────────────────────────┘
```

**컬럼:** 학생단체명 / 기업명 / 행사 / 수량 / 협찬상태 / (후기작성 버튼)

**빈 상태:** "등록된 협찬 요청이 없어요." + [+ 협찬 요청하기] 버튼

**상태 표시:** DB 영문 값을 한글로 변환해서 표시 (Thymeleaf switch)

| DB 값 | 화면 표시 |
|-------|---------|
| PENDING | 대기중 |
| APPROVED | 승인 |
| DONE | 완료 |
| REJECTED | 거절 |
| REVIEWED | 후기완료 |

**후기작성 버튼 상태별 동작:**

| 협찬상태 | 버튼 |
|---------|------|
| PENDING / APPROVED | 회색 텍스트 (클릭 불가) |
| DONE | 링크 활성화 → 후기작성 페이지 이동 |
| REVIEWED | "작성완료" 텍스트 표시 (클릭 불가) |
| REJECTED | 표시 안 함 |
