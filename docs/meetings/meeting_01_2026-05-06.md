## 논의 내용

### 1. 팀 구성

- 수업 시간 중 팀 빌딩 진행
- 최아영: 수업 시간 중 팀에 합류하여 아이디어 제안은 다음 기회로 미룸

### 2. 아이디어 제안

**박서윤** — 항공편 관리 시스템
- 항공편 일정·좌석·예약 정보를 DB로 관리하는 시스템

**이수빈** — 미제사건 시민 제보 게시판
- 시간이 지나며 잊혀지는 미제사건을 시민 협력으로 다시 조명하는 시스템
- 시민이 사건 정보를 찾아보고 단서·목격담을 한곳에 제보 가능
- 관심 사건 북마크, 사건 유형별·지역별 통계 기능 포함
- 핵심 테이블: 사용자, 사건, 사건유형, 제보, 관심등록 (5개)
- 컨셉: "잊혀진 사건을 시민 협력으로 다시 들여다본다"

**이서아** — 협찬 통합 관리 시스템 ✅ 확정
- 학생단체·인플루언서·기업의 협찬 요청부터 후기까지 한 시스템에서 처리
- 기존에 카카오톡·메일·DM·엑셀에 흩어진 협찬 이력을 DB로 통합 관리

### 3. 기술 스택 초안

- 언어: Java
- GUI: Java Swing (데스크톱 애플리케이션)
- 데이터베이스: MySQL
- DB 연결: JDBC
