## 논의 내용

### 1. Docker 제거

- 로컬 환경 세팅 복잡도를 줄이기 위해 Docker 미사용으로 결정
- **로컬 MariaDB 직접 설치 + IntelliJ/VSCode 실행 방식**으로 확정

### 2. ERD 최종 확정

- 테이블 5개로 확정 (student_org, event, company, sponsorship_request, review)
- 홍보효과·홍보계획 컬럼 제거
- 기업은 상품 하나만 제공한다고 가정 → 카테고리 컬럼 불필요
- 협찬 이력 테이블은 v2로 연기
- schema.sql, seed.sql 작성 완료 (기업 10개, 협찬 50건 이상, 6개월 분산)

### 3. 기술 결정

- Spring Security 없이 HttpSession으로 로그인 처리
